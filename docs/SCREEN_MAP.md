# Screen map

| View | Purpose | Main API calls |
|---|---|---|
| Overview | KPI tiles, stage timeline, C/Cr/Si/T with uncertainty band, gas practice, alarms, mini 3D, schematic | `POST /v1/simulations/demo/{id}` |
| 3D Vessel | Interactive vessel: cutaway, X-ray, labels, replay scrubber, snapshot PNG, 2D fallback | run series + geometry |
| Process Schematic | All regions and utilities with live values; replay; SVG download | run series |
| Furnace Design | Capacity presets, dimensions, tuyeres, lance, lining layers; to-scale section; lining profile; shell loss | `POST /v1/design/preview`, re-run |
| Charge & Recipe | Grade targets, transfer assay (validated), carry-over slag, stage table (flows, gas, criteria), timed additions, parameters | `GET /v1/grades`, `GET /v1/recipes/{g}`, `POST /v1/simulations/run` |
| Trends | 12 charts: C with C_eq (log), Cr window, alloys, N/S with N_eq, temperatures (incl. critical T), flows, pCO, decarb/Cr rates, O distribution, stirring, a_O, weights | run series |
| Mass Balance | Inputs and outputs with compositions, element closure table, Cr/C Sankey, final composition, weights, gas | run summary |
| Heat Balance | Sources and sinks, MW flows, lining profile, hot face/shell/wear, energy account | run summary |
| Slag & Recovery | Stacked composition, basicities and Λ, Cr₂O₃ saturation, Cr recovery, viscosity/foaming, L_S | run series |
| Off-Gas | Vessel vs duct vs analyzer, flows/T, C removal, O₂ destination | run series |
| Thermo Explorer | Hilty diagram, critical T, N solubility, ΔG°, reaction registry | `GET /v1/thermo/explorer`, `/v1/meta` |
| ML & Confidence | Fault injection, EKF vs truth vs physics, gate; hybrid prediction; model card | `/v1/estimation/reconcile`, `/v1/ml/predict`, `/v1/ml/model-card` |
| MPC Advisor | Weights, decision time, gates; recommendation contract; approve/reject/modify; trajectories; Pareto; alternatives | `/v1/mpc/recommend`, `/v1/advisory/{id}/review` |
| Scenario Lab | Scenario library; branch variants; compare overlays and deltas | `/v1/scenarios/{id}/run`, `/v1/scenarios/compare` |
| Economics & CO₂ | Cost breakdown, shares, CO₂ by scope, editable tariffs → re-run | run economics |
| Reports | HTML report (print to PDF), CSV, JSON, timeline, events, assumptions | `/v1/reports/{run}` |
| Settings & Audit | API URL/key, operator/role, theme, reduced motion, safety statement, audit chain, data dictionary | `/v1/audit/{heat}`, `/v1/data-dictionary` |

Screenshot locations are in `screenshots/<view>.png` of the deliverable set (generated by `tests/e2e/smoke.mjs`).
